# Управленческая отчётность сети клиник и ИИ-агент (демо на синтетических данных)

Учебно-демонстрационный проект: сборка отчётности из выгрузок «1С» и «ERP», контроль качества данных и сверка с бухгалтерией,
P&L, план-факт, факторный анализ валовой маржи, ДДС с мостом «прибыль → деньги», аналитика врачей, калькулятор надбавок за KPI,
дашборд и ИИ-агент на Claude. Все данные синтетические: сеть из 3 клиник и 5 направлений, 2025 год, 66 411 визитов, 43 врача,
выручка 825,2 млн ₽.

## Что внутри и что получается

| Блок | Скрипт | Результат |
|---|---|---|
| Данные | `src/generate/` | ERP (визиты, услуги, врачи), «1С» (проводки, ОСВ, платежи), бюджет |
| Сверка 1С и ERP | `src/reconcile/` | `findings.csv` и отчёт: принцип «объясняй и вычитай», допуск 100 ₽ на ячейку |
| P&L | `build_pnl.py` | `PnL_2025.xlsx`: фильтры клиника и направление, сверка с ОСВ |
| План-факт | `build_planfact.py` | `PlanFact_2025.xlsx` |
| Факторный анализ | `build_factor.py` | `FactorAnalysis_2025.xlsx`: валовая маржа план → факт, 11 факторов |
| Врачи | `build_doctors.py` | `DoctorAnalytics_2025.xlsx`: грейды, повторные визиты, сезонность |
| Мотивация | `build_motivation.py` | `MotivationCalc_2025.xlsx`: калькулятор надбавок за KPI (живые формулы) |
| Деньги | `build_cashflow.py` | `CashFlow_2025.xlsx`: ДДС прямым методом и мост «прибыль → деньги», сверка с сч. 51 |
| Дашборд | `build_dashboard.py` | `Dashboard_2025.html`: 4 вкладки, фильтр клиники |
| ИИ-агент | `src/agent/` | Claude + инструменты, проверка чисел в ответах |

Книги Excel живые: формулы пересчитываются при смене параметров (жёлтые ячейки). Значения формул сохраняются через LibreOffice.

## Ключевые результаты (контрольные цифры)

- Сверка 1С и ERP: 14 из 14 заложенных ошибок найдено, ложных 0, сумма под риском 2,34 млн ₽. На втором наборе ошибок,
  который правила не видели, найдено 7 из 13 (54%): честный тест обобщаемости.
- Слепой тест: на втором наборе ошибок найдено 7 из 13. Не замечены опечатка количества, проведённая одинаково в 1С и ERP,
  врач другой клиники в визите и один врач у двух пациентов одновременно: согласованность систем не доказывает верность цифры.
  На первом наборе автоисправление вернуло выручку 1С к исходной с точностью до 174 ₽ по ячейкам, ERP совпал с исходными
  данными, кроме двух визитов без врача (намеренно не исправляются). На слепом наборе автоисправление не запускалось.
- Валовая маржа: план 291,43 → факт 268,10 млн ₽ (−23,33), разложена на 11 факторов. Прибыль до налога 179,56 → 158,05 млн ₽.
- ДДС и мост «прибыль → деньги» сходятся с оборотами счёта 51 до копейки по каждому месяцу и клинике: деньги +185,04 млн ₽,
  остаток 216,04 млн ₽.
- Надбавки за KPI по умолчанию: +1,60 млн ₽ с взносами (+0,49% к оплате врачей), условие выполняют 7 из 43 врачей.

## Агент

Модель не считает: выбирает инструмент (`pnl`, `margin_bridge`, `top_drivers`, `cashflow`, `doctors`, `events`, `data_quality`,
, `write_report`), получает готовые числа и объясняет их. После ответа `verify.py` ищет каждое число в выводах инструментов
и помечает не найденные. Ключ ответов агенту недоступен. `src/agent/eval.py` прогоняет 8 вопросов с известным ответом.

Состояние проверки: инструменты и обвязка проверены офлайн (`tests/test_agent_offline.py`, 23 проверки). Живые прогоны
с моделью записываются в `docs/agent_examples/`.

## Запуск (Windows, PowerShell, Python 3.11+)

```
cd C:\merdclinic_vc
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONUTF8 = "1"
python run_all.py
```

LibreOffice нужен, чтобы в книгах сохранялись значения формул: `winget install TheDocumentFoundation.LibreOffice`.
Без него отчёты соберутся, но без кэша значений (в предпросмотре на телефоне ячейки будут пустыми).

Агент:
```
$env:ANTHROPIC_API_KEY = "ключ"
python src\agent\agent.py "Почему упала валовая маржа в мае?"
python src\agent\agent.py --summary "Резюме для директора за 2025 год"
python src\agent\eval.py
```

## Ограничения

- Данные синтетические; внутри направления врач почти не влияет на возврат пациентов, поэтому KPI «повторные визиты»
  в калькуляторе мотивации в основном ловит шум.
- P&L заканчивается прибылью до налога; налога на прибыль и НДС нет. Взносы 22% плоской ставкой.
- Плана по деньгам нет (бюджет составлен по P&L), поэтому план-факт ДДС не строится. Финансовой деятельности нет.
- Дебиторка ДМС в ОСВ одним сальдо, срок оплаты по страховым не определяется.
- Калькулятор мотивации считает стоимость схемы на фактических данных, поведение врачей не моделирует.
- Малая выборка: 6-12 врачей на направление, выводы по отдельному врачу делать нельзя.
- 2 визита без врача (120 700 ₽) намеренно не исправляются и показаны отдельным остатком.
- Три расхождения выручки исправлены эвристикой: в реальной работе их нужно подтвердить бухгалтером.
